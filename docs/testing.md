# 实机验收清单

编译和纯状态机测试不能替代此清单。每个平台分别记录设备型号、系统版本、应用版本、权限状态和实际结果；未做的项目保持“待验证”。

| 场景 | 预期 |
| --- | --- |
| 初次启动 | 显示用途与设备试测入口，不自动拦截输入 |
| 权限不足／安全输入启用 | 不进入清洁；解释原因 |
| 中文／英文／其他系统语言 | 中文／英文／英文；内容不截断 |
| 随机组合 | 四个不同字符，排除 O0I1 |
| 无效自定义组合 | 不允许开始；说明有效字符 |
| 记住组合后重启 | 自定义值保留；不自动开始 |
| 初始四键识别 | 非四键、重复、错误键不能跳过检测 |
| 四键识别后松开 | 全部松开才进入 3 秒倒计时 |
| 倒计时中按键／移动鼠标 | 取消倒计时，要求重新检测 |
| 清洁中的普通字母／快捷键／媒体键 | 不改变其他应用或系统状态（明确保留操作除外） |
| 内置／外接鼠标 | 移动、点击、拖动、滚轮无效 |
| 触控板 | 轻点、物理点击、滚动、缩放、旋转和系统多指手势无效 |
| 恰好四键长按 4.9 秒 | 未解锁 |
| 恰好四键长按满 5 秒 | 解锁，提示松开 |
| 长按中松开一个键 | 圆环立即归零 |
| 长按中增加第五键或修饰键 | 圆环立即归零 |
| 同时按左右修饰键再分别松开 | 尚未松开的修饰键仍使解锁无效 |
| 键盘自动重复 | 不重复启动／提前完成解锁 |
| 清洁满 180 秒 | 自动恢复；不得额外等待用户松键 |
| 手动解锁后仍按着键 | 有界松键过渡，不无限锁定；提醒用户松手 |
| 多次开始／结束 | 无残留钩子、无重复窗口 |
| 新插拔键盘／鼠标／触控板 | 终止当前会话，要求重新试测 |
| Windows 触控设备／能力检测失败 | 阻止开始；不永久禁用设备 |
| Windows UAC／锁屏／安全桌面切换 | 结束保护，不宣称安全桌面被覆盖 |
| 系统休眠／用户切换 | 结束当前保护，恢复后不自动重锁 |
| UI 线程停住 | 输入线程心跳检查结束保护 |
| 输入线程／整个应用停住 | 独立监督进程结束所属应用，系统释放钩子 |
| 正常关闭／强制结束应用 | 键盘鼠标恢复，监督进程退出 |
| 试测确认否／不确定 | 不开放正常清洁 |
| 系统／应用／设备变化 | 旧试测资格失效 |

只使用没有重要内容的窗口测试输入漏出。不要使用电源长按、删除文件或发送消息等动作作为测试素材。对任何未覆盖的输入路径记录“不通过”，而不是把它解释为允许的例外。

## 自动化覆盖

- 两个平台的纯状态机：字母校验、四键预检、准备取消、精确长按、额外键、重复、超时、松键过渡。
- Mac 独立监督进程测试只创建可丢弃的测试子进程，不安装输入拦截。
- CI 负责测试和构建，不在无人值守环境中启动全局输入锁定。
- Windows CI 运行于 Windows Server 构建机器，不能据此宣称通过了 Windows 11 物理设备验收。

# KeyPossum 0.1.0 Alpha 1

键盘装死，安心擦擦。首个原生版本。项目用户已在 macOS 与 Windows 两台目标设备上确认运行和功能正常。

- macOS 26+ Apple Silicon 与 Windows 11 x64 非触控屏设备。
- 四个不同字母／数字，随机或自定义并保存在本机。
- 开始前四键检测，3 秒准备倒计时。
- 精确四键长按 5 秒解锁，最长 180 秒自动恢复。
- 小窗口置顶，中英文跟随系统，负鼠主题图标。
- 首次 15 秒设备试测；用户确认全部输入无效后才可正常清洁。

## Alpha 限制

本版本不是对所有硬件的兼容性承诺。请阅读仓库 `docs/verification.md` 中已做和待做的验证。先尝试普通按键、媒体键、鼠标及触控板多指手势；有任何漏出时不要清洁。

Windows 触控屏暂不支持。电源、固件与系统保留操作不受保护。首版没有商业代码签名或 Apple 公证，安装时可能出现安全提示。

下载 `macos-arm64.zip` 或 `windows-x64.zip`。Windows 请保留解压后的所有文件，运行 `KeyPossum.exe`。自动生成的 Source code 下载项不是应用安装包。

## 已知保护边界

系统保留操作、固件、电源、专用驱动和受保护桌面无法由普通应用统一控制。Windows 的低级钩子可能被系统静默移除；工作线程心跳不能证明钩子仍实际拦截事件。Mac 媒体键和多指手势也需要实机确认。

不同键盘上相同扫描键位的输入无法由这类 Windows 钩子归属到独立设备。非标准布局、多个设备共同按键及驱动配置变化均需要重新试测。软件本身不能代替用户观察是否漏出。

监督期限依赖系统正常调度，无法对整个操作系统卡死提供硬实时保证。没有安装任何设备驱动或修改系统手势设置。

# 安装与首次试测

## Mac（Apple 芯片，macOS 26+）

1. 解压 `KeyPossum-0.1.0-alpha.1-macos-arm64.zip`，将 `KeyPossum.app` 拖入“应用程序”。
2. 双击打开。首版仅作本地临时签名，没有 Apple 公证。如果系统阻止打开，在确认来源后，使用“系统设置 → 隐私与安全性”中的单应用“仍要打开”流程。不要关闭系统整体安全保护。
3. 在应用中点击“授予权限”。按系统提示，在“隐私与安全性 → 辅助功能”和“输入监控”中允许 KeyPossum。授予后退出并重新打开。
4. 显示英文是正常的：应用跟随系统首选语言。把系统首选语言设为中文后重新启动才会显示中文。

每次重新构建可能改变临时签名，系统可能要求重新授权。先把应用固定放在“应用程序”再授权，避免反复移动。

## Windows（Intel／AMD x64，Windows 11）

1. 解压 `KeyPossum-0.1.0-alpha.1-windows-x64.zip` 到一个固定文件夹。
2. 保留文件夹中所有文件，不要只拿走 EXE。运行其中的 `KeyPossum.exe`。发布包已包含 .NET 运行时。
3. 如需管理员授权，确认程序来源后批准 UAC 提示。首版没有商业代码签名，系统可能提示发布者未知。
4. 如果系统检测到触控屏，首版会阻止进入清洁模式。请不要为了跳过检查去禁用设备或改系统注册表。

## 先做设备试测

先保存正在编辑的内容，准备一个没有重要内容的测试窗口。不要在试测尚未确认时就开始擦拭。

1. 输入／随机生成四个不同的字母或数字。自定义输入不包含 `O/0/I/1`。
2. 点击“开始设备试测”，同时按住显示的四键，系统识别后松开全部按键。
3. 静待 3 秒。准备期间有任何输入会取消倒计时。
4. 15 秒试测期间，主动尝试：普通字母、快捷键、音量亮度媒体键、鼠标移动／点击／滚轮、触控板轻点／滚动／缩放／三指四指手势，以及已连接的外接设备。
5. 到时输入恢复。只有确认上述输入均未作用到系统或其他应用时，才选择“全部无效／All blocked”。漏出或不确定就选择否。

电源键、固件操作和系统保留恢复通道不属于试测通过标准，不要以长按电源作为测试动作。请使用标准英文键帽对应位置；非标准布局先验证组合。

## 正常清洁

通过试测后，点击“开始清洁”，再次完成四键检测。清洁期间窗口显示组合和剩余时间。只按这四个键 5 秒，圆环走满后松开；少按、多按或加入 Shift 等其他键都会重置进度。也可以等待 180 秒自动恢复。结束后应用留在窗口。

设备连接发生变化、系统或应用升级后需要重新试测。窗口的确认标记代表用户的本机试测结果，不是软件自动认证。

## 异常恢复

输入线程检查 UI 心跳，独立监督进程检查输入线程心跳和期限。一般异常会结束保护；严重卡死可能直接结束 KeyPossum 进程，让系统释放拦截。

如果输入未按预期恢复，先等待自动恢复期限。在 Windows 上可使用系统保留的 `Ctrl+Alt+Del`。系统本身完全失去响应时，应用无法保证恢复时限。请记录设备和步骤，提交问题后再继续测试。

本工具不保证覆盖安全桌面、远程会话或厂商驱动提供的特殊输入。发现漏出时，停止使用清洁模式。
